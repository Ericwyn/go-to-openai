# Auto 交互式模式使用说明

Auto 模式提供了一个交互式命令行界面，通过数字选择快速完成证书管理、配置生成和代理启动等操作。

## 启动方式

### 交互式模式

```bash
sudo ./go-to-openai auto
```

### 非交互式一键启动

适用于已完成配置的用户，直接跳过交互菜单执行一键启动：

```bash
sudo ./go-to-openai autostart
```

> **注意**：两种模式都需要管理员（Windows）或 root（Linux/macOS）权限。

## 菜单选项

启动后显示以下菜单：

```
欢迎使用 goto-openai, 请输入数字进行操作
1. 生成根证书
2. 安装根证书
3. 卸载根证书
4. 生成域名证书
5. 生成配置文件
6. 添加hosts配置
7. 删除hosts
8. 配置检查
9. 一键启动
0. 退出
```

## 功能说明

### 1-3. 根证书管理

- **生成根证书**：在 `./cert/` 目录下生成 `goto-openai-root.crt` 和 `goto-openai-root.key`
- **安装根证书**：将根证书添加到系统信任存储
- **卸载根证书**：从系统信任存储移除根证书

### 4. 生成域名证书

提示输入域名（支持多个域名，用逗号或空格分隔），为每个域名生成独立的证书文件。

示例输入：
```
api.openai.com api.anthropic.com
```

生成的文件：
- `cert/goto-openai-dm-api.openai.com.crt`
- `cert/goto-openai-dm-api.openai.com.key`

### 5. 生成配置文件

提示输入代理域名，生成 `auto.config.json` 配置文件。

配置文件模板包含：
- 监听地址：`:443`
- 证书路径：自动指向对应域名证书
- 3 个默认路由：`/v1/chat/completions`、`/v1/models`、`/v1/responses`

### 6. 添加 hosts 配置

提示输入域名（支持多个），自动将域名指向 `127.0.0.1`。

### 7. 删除 hosts

删除所有 go-to-openai 相关的 hosts 配置，需要用户确认。

### 8. 配置检查

输出配置检查报告，包括：
- 根证书是否存在
- 配置文件是否存在及内容摘要
- hosts 是否已配置
- hosts 配置与配置文件是否匹配

### 9. 一键启动

自动完成以下所有步骤：

1. **读取配置**：加载 `auto.config.json`（不存在则提示先生成）
2. **检查/生成根证书**：如不存在则自动生成
3. **生成域名证书**：基于最新根证书为配置中的所有域名生成证书
4. **配置 hosts**：自动将配置中的域名指向 `127.0.0.1`
5. **启动代理**：启动 HTTPS 代理服务器

## 使用流程示例

### 首次使用（推荐一键启动）

```bash
# 1. 以管理员/root 身份启动
sudo ./go-to-openai auto

# 2. 选择 5，输入域名生成配置
# 3. 选择 9，一键启动（自动完成证书、hosts、启动）
```

### 手动分步操作

```bash
sudo ./go-to-openai auto

# 按顺序选择：
# 1 → 生成根证书
# 2 → 安装根证书
# 4 → 生成域名证书（输入 api.openai.com）
# 5 → 生成配置文件（输入 api.openai.com）
# 6 → 添加 hosts（输入 api.openai.com）
# 8 → 配置检查（确认一切正常）
# 9 → 一键启动
```

### 恢复原样（清理环境）

如需完全恢复系统到使用前的状态，请按以下步骤操作：

```bash
sudo ./go-to-openai auto

# 1. 选择 7 → 删除 hosts 配置
# 2. 选择 3 → 卸载根证书
# 3. 手动删除证书文件：rm -rf cert/  （Windows: 删除 cert 文件夹）
# 4. 手动删除配置文件：rm auto.config.json
```

**恢复步骤说明：**
- **删除 hosts**：移除所有指向 `127.0.0.1` 的域名配置，域名将恢复正常的 DNS 解析
- **卸载根证书**：从系统信任存储中移除 `goto-openai-root` 证书
- **删除证书文件**：清理 `cert/` 目录下生成的所有证书和密钥文件
- **删除配置文件**：移除 `auto.config.json` 配置文件

> **注意**：如果使用的是 Windows bat 脚本启动，关闭代理服务器后按 `Ctrl+C` 即可停止。
